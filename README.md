# PARAOMEUAMOR

Repositório do site "Um Livro Chamado Nós".

## Como abrir localmente

1. Abra a pasta do projeto.
2. Execute um servidor local, por exemplo:
   - `python -m http.server 8000`
3. Acesse: `http://localhost:8000`

## Estrutura

- `index.html` — página principal
- `styles.css` — identidade visual e layout
- `script.js` — animações e contador

## Personalização

- Troque as imagens na pasta para fotos reais do casal.
- Ajuste textos e capítulos conforme a história de vocês.
- Publique no GitHub Pages quando quiser.
